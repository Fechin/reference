## Getting Started {.cols-2}

### Quick Add Elements

| Shortcut | Action |
| --- | --- |
| `T` | Add text box |
| `R` | Add rectangle |
| `C` | Add circle |
| `L` | Add line |
| `S` | Add sticky note |
| `/` | Open Canva Magic / Quick Actions |

{.shortcuts}

### Essential Actions

| Shortcut | Action |
| --- | --- |
| `Ctrl` `Z` | Undo |
| `Ctrl` `Shift` `Z` | Redo |
| `Ctrl` `A` | Select all elements |
| `Esc` | Deselect elements / Exit tool |
| `Ctrl` `C` | Copy |
| `Ctrl` `V` | Paste |
| `Ctrl` `Alt` `C` | Copy style |
| `Ctrl` `Alt` `V` | Paste style |
| `Delete` | Delete selected element |

{.shortcuts}

## Object Manipulation {.cols-2}

### Arrange & Layering

| Shortcut | Action |
| --- | --- |
| `Ctrl` `]` | Bring forward |
| `Ctrl` `[` | Send backward |
| `Ctrl` `Alt` `]` | Bring to front |
| `Ctrl` `Alt` `[` | Send to back |
| `Ctrl` `G` | Group elements |
| `Ctrl` `Shift` `G` | Ungroup elements |
| `Ctrl` `D` | Duplicate element |
| `Alt` `Drag` | Duplicate by dragging |

{.shortcuts}

### Selection & Sizing

| Shortcut | Action |
| --- | --- |
| `Shift` `Click` | Select multiple elements |
| `Shift` `Drag` | Constrain proportions when resizing |
| `Alt` `Drag` | Resize from center |
| `Ctrl` `Click` | Select element behind overlapping layer |
| `Shift` `R` | Show/hide rulers |
| `Ctrl` `;` | Show/hide guides |

{.shortcuts}

### Positioning & Nudging

| Shortcut | Action |
| --- | --- |
| `↑` `↓` `←` `→` | Nudge element by 1px |
| `Shift` `↑` `↓` `←` `→` | Nudge element by 10px |
| `Ctrl` `Shift` `L` | Align elements to the left |
| `Ctrl` `Shift` `C` | Align elements to center |
| `Ctrl` `Shift` `R` | Align elements to the right |

{.shortcuts}

### Canvas & View

## Presentation Mode {.cols-2}

### Presentation Controls

| Shortcut | Action |
| --- | --- |
| `Ctrl` `Alt` `P` | Enter Present / Full-screen mode |
| `Right` / `Space` | Next slide |
| `Left` | Previous slide |
| `Esc` | Exit Present mode |
| `W` | White screen toggle |

{.shortcuts}
